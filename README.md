# -nail-technician-
A nail technician portfolio showcasing beautiful nail designs, creative nail art, manicure and pedicure services, and professional nail care.
Nail Technician Booking and Management System

A responsive web-based system that allows customers to book nail appointments and manage their bookings online.

Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

Features

- Homepage
- Nail services and prices
- Nail design gallery
- Appointment booking
- View and cancel bookings
- Management dashboard
- Export bookings to CSV

How to Run

1. Download and extract the project.
2. Open the folder in VS Code.
3. Run "index.html" using Live Server.

Note: This is a frontend-only project. No PHP, database, registration or login is required. Bookings are stored in the browser's LocalStorage.
